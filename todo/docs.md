What this mod does?
With a console command, it cleans the fertilizer state/layer of the specified field (or the field the player is above). 
In multiplayer only admin's can execute the command.

Add the command with examples in `code blocks`

Reason of existence? 
- We were running a relative realistic mutliplayer server which wanted to fertilize the same fields with multiple pass of fertilizers. Because the fertilizer state was already painted we wanted to be able to clear this layer on fields, to let us spread fertilizers again.
- We could have use the EasyDeveloperConrols mod to achive the same result, but that updates multiple properties of the fields, for example row orientation
- RowCropSystem is used in our game, so row orientation is not something we want to loose,
- If something was planted with same time fertilization, spreading on the field was impossible
